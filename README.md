## Building from source

Uses the recommended setup for KenshiLib mods.
Refer to the [KenshiLib README](https://github.com/BFrizzleFoShizzle/KenshiLib/tree/18f75fecb93cfead6029efe0d5fe199d6618bcc9) for instructions on how to set up a KenshiLib mod environment.
The build scripts require `MSBUILD_PATH` to be set in your environment variables, pointing to the bin folder of the MSBuild executable for whichever version of Visual Studio you are using.
Using Visual Studio 2026 or newer should work, but the build tools of the project need to be set to v100 (VS2010) in order to build the mod.

## Requirements (for the mod to work)

- [RE_Kenshi](https://www.nexusmods.com/kenshi/mods/847) v0.34 or later
- Kenshi v1.0.65+
